## 2. Staffing model

- Each seed Circle gets **1 owner from Founding 500** (they applied to lead it) + 1 Nia moderator as backup
- Circle owner duties: 3 posts/week minimum, answer every new member within 24h, run 1 weekly prompt
- Reward: Leader badge, featured placement, early creator tools, merch
- Nia team runs #17 Jobs Board and #19 Scholarships Radar directly (quality guarantee on the retention hooks)

## 3. Seeding cadence (pilot weeks)

- Week 1: create all 25; owners post intros; 20+ members each from Founding 500
- Week 2: daily prompts per Circle; first opportunities posts (10+ real listings verified by Nia team)
- Week 3: first events — 5 virtual Circle meetups + 2 campus pop-ups; test RSVP flow
- Exit gate: every seed Circle ≥20 members, ≥3 posts in last 7 days, ≥1 opportunity posted

## 4. WhatsApp bridge strategy

WhatsApp is the distribution nervous system (~95%+ of internet users in wave-1 markets):
1. One Nia market group per country (moderated, links-only + announcements)
2. Every Circle gets a share card ("I just joined X on Nia") that unfurls with OG image into WhatsApp/Status
3. Weekly "Opportunities Drop" formatted as a forwardable WhatsApp message with 3 listings + link
4. Never run community *inside* WhatsApp — the group's only job is pushing members into Circles

## 5. Launch-day flow for a brand-new user

1. Sign up (email, 60s) → onboarding picks interests → **recommended Circles appear immediately** (seeded, alive)
2. Join ≥1 Circle → see real posts + opportunities posted this week
3. Notification within hours (Circle welcome, prompt) → return next day
4. Founding member badge + 5 invites → bring their group chat
